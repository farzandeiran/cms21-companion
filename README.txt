همراه آفلاین Car Mechanic Simulator 2021

محتویات:
- index.html: برنامه
- manifest.webmanifest و sw.js: پشتیبانی نصب PWA و کش آفلاین در میزبانی HTTPS

بانک خودروها:
- 227 خودرو/گونه از راهنمای جامعه‌محور Steam (شامل بازی پایه و دسته‌های DLC)
- 57 برند
- انتخاب برند و سپس مدل/گونه از فهرست مرتب‌شده
- نوع محتوای هر خودرو در کنار نام نمایش داده می‌شود.
- موتور پیش‌فرض و تعویض‌های سازگار در منبع فعلی برای همه خودروها اعتبارسنجی نشده؛ موتور را مطابق بازی دستی انتخاب کنید.

کاتالوگ قطعات:
- گروه Cylinder Head (سر سیلندر) اضافه شده است.
- گروه‌های Engine Block، Timing، Fuel & Intake، Cooling، Lubrication و Exhaust نیز وجود دارند.
- کاتالوگ قابل ویرایش است و قطعات نمونه را می‌توانید حذف/اضافه کنید.

استفاده آفلاین:
- فایل index.html را می‌توان مستقیماً در مرورگر باز کرد؛ ذخیره محلی به همان مرورگر/دستگاه وابسته است.
- نصب PWA و کش کامل آفلاین از طریق HTTPS و گزینه Add to Home Screen / Install App در Chrome انجام می‌شود.
- برای انتقال اطلاعات از خروجی پشتیبان JSON استفاده کنید.
